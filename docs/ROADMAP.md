# Production roadmap

## Milestone 1 — playable foundation
- [x] Unity project structure and project metadata
- [x] Fighter movement and facing controller
- [x] Health and knockout events
- [x] Light/heavy hit detection and block foundation
- [x] Dynamic two-fighter camera framing
- [x] Round/match state foundation
- [ ] Unity editor scene assembly and playtest
- [ ] Gamepad input and remappable controls

## Milestone 2 — first vertical slice
- [ ] Two original, production-quality fighter designs
- [ ] Complete frame-based combat animation sets
- [ ] One fully illustrated arena with layered parallax
- [ ] HUD: health, timer, round markers, combo feedback
- [ ] Hit-stop, hit stun, pushback, cancel windows, and combo rules
- [ ] Audio: impacts, movement, ambience, and music

## Milestone 3 — complete game loop
- [ ] Character select and versus presentation
- [ ] CPU opponent with difficulty levels
- [ ] Local two-player match flow
- [ ] Best-of-three rounds, timer, rematch, and results
- [ ] Accessibility, settings, and input remapping

## Milestone 4 — polish and release
- [ ] Additional fighters and arenas
- [ ] Performance and input-latency pass
- [ ] QA matrix and regression tests
- [ ] Build pipeline and release packaging

## Definition of done for a milestone

A milestone is complete only after the feature is integrated into a Unity scene, tested in Play Mode, and documented. A source file existing in the repository is not proof of a tested feature.
